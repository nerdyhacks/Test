## 🎨 Color Scheme

- **Primary Orange**: #ff6b35 (Brand color for headings, buttons, accents)
- **Gradient**: Orange to #f7931e (Hero section background)
- **Text**: #333 (Dark headings), #666 (Body text)
- **Background**: White with light gray (#f8f9fa) alternating sections
- **Cards**: White with subtle shadows

## 📱 Key Visual Elements

### Typography
- **Headings**: Inter font, bold weights (600-700)
- **Body**: Inter font, regular weight (400)
- **Clean hierarchy**: Large hero text → section headers → body text

### Interactive Elements
- **Buttons**: Orange primary, white secondary with orange border
- **Hover effects**: Subtle lift and color changes
- **Mobile menu**: Hamburger menu that slides in from left
- **Smooth scrolling**: Between sections

### Layout Features
- **Fixed header**: Always visible for navigation
- **Grid layouts**: Responsive cards and sections
- **Stats cards**: Prominent numbers with clean styling
- **Icon integration**: Emoji icons for visual interest
- **Progressive disclosure**: Information organized in digestible chunks

### Mobile Responsive
- **Stacked layouts**: Cards stack vertically on mobile
- **Touch-friendly**: Large buttons and touch targets
- **Optimized text**: Readable sizes across all devices
- **Mobile menu**: Clean slide-out navigation

## 🎯 Key Messaging for Civic Leaders

The design emphasizes:
1. **Credibility**: 35+ years, 501(c)(3) status, 220+ branches
2. **Non-political nature**: Clearly stated to reassure government officials
3. **Community impact**: Concrete examples of recent service
4. **Partnership opportunities**: Clear calls-to-action for collaboration
5. **Professional presentation**: Clean, government-appropriate aesthetic

The website successfully presents HSS USA as a trustworthy, established organization focused on community service and civic engagement, perfect for building relationships with civic and community leaders.
